# HCIE-DataCom数通v1.0题目解法

# 1、传统网改造及升级
关于本部分，建议通读6个需求后进行一次性配置。
- a、配置出口路由器 X_T1_Export1 和 X_T1_Export2
  出口路由器有以下需求：
  - 1、vlan配置
  - 2、三层接口配置+二层物理口配置
  - 3、路由策略+acl策略
  - 4、OSPF配置
  - 5、BGP配置
  - 6、NAT配置
  - 7、默认路由
- b、核心交换机配置：
  - vpn隔离 通过vrf实例实现
  - vlan创建
  - dhcp创建
  - acl策略+重定向
  - ip-prefix
  - 互联vlan201-209
  - 业务vlan 51-55 100-105 60
  - 物理口互通、二层口放行vlan
  - lo0口配置
  - ospf配置
  - dhcp地址池绑定实例
- c、汇聚交换机配置：
  - vlan池
  - 环回口 vlanif口
  - 链路聚合放行vlan 上联trunk 下联hybrid
  - OSPF
  - 802.1x准入
- d、接入交换机配置：
  - 802.1x透传
  - 链路聚合放行
  - 接AP的需要放行vlan100 不接ap的不需要配置
- e、AC配置：
  - vlan配置51-55 100-105 203
  - 环回口配置
  - ospf配置
  - vlan池扩容配置
  - vap模板选择vlan池
  - X_T1_AP和X_T2_AP上线，确认ap组和ap名
- f、防火墙配置：
  - vsys配置
  - vlan204-207 环回口1.2.3加入vsys
  - 二层口放通vlan
  - 静态路由
  - ospf配置
  - 虚拟墙内区域划分、地址对象创建
  - 安全策略

出口路由器1、2 脚本说明：
>考试按这个顺序写完检查无误刷写即可。

1、拓扑说明：出口路由器1即是X_T1_Export1,g0/0/1 也就是1口连接核心交换机的1口 通过vlan201通信，vlan201配置vlanif接口地址为10.1.200.1/30；7口对接Z广域承载网区X_PE1的g0/0/10口，配置互联IP为10.20.1.1/30，8口与出口路由器2的8口互联，配置互联IP地址为10.20.1.5/30。请注意，默认情况下出口路由器1、2的g0/0/7、G0/0/8口都为2层口，且被STP生成树阻塞，需要手动 undo portsw切换为3层口才可以配置IP地址。G0/0/9和G0/0/10模拟对接运营商ISP 对接互联网。接口IP为10.255.1.1/24和10.255.2.1/24
1、创建vlan 建议第一件事情就是创建vlan 否则配置vlanif地址后 物理口二层放通后，如果未创建vlan 接口会down 且容易忽视，为排错带来困难。
2、关于三种策略的说明：
    acl 2000，建议在脚本的开头放通，在nat中会调用，如果开头不写acl 在9口和10口调用nat out 2000会报错
    ip ip-prefix xgr允许x园区的访客用户访问互联网，
    route-policy tag 三个节点策略 1是拒绝tag值为10的路由发布出去（防环），2是拒绝访客路由与YZ园区互通 
3、配置BGP协议，题目明确标注X园区属于AS65001 ，然后BGP ipv4单播对等体指向X_PE1（10.20.1.2） 调整prefrence优先级为140 255 255，引入ospf路由（即XYZ路由层面互通）
4、配置OSPF协议：配置下发默认路由、配置cost type1 引入bgp路由  骨干区域发布自己网段lo0地址、vlanif201地址、出口路由器1互联出口2地址。
5、提速技巧：写完出口1脚本，复制为出口2脚本，进行修改会大大缩减时间，记住出口1、2的差异点即可。

X_T1_CORE1核心交换机：
G0/0/1口互联出口1 放行vlan201
G0/0/2口互联出口2 放行vlan202
G0/0/3口互联AC 放行51-55 101-105业务 互联vlan203 无线隧道vlan100
G0/0/4口互联防火墙G1/0/1（有的是0/0/1 看考试机架而定）
G0/0/5口互联防火墙G1/0/2
G0/0/6口互联服务器交换机
vlan 201 202 互联出口路由器
vlan203 互联AC
vlan 204 205 互联防火墙
vlan 206 207 互联防火墙（实例绑定）
vlan 208 209 互联T1、T2汇聚交换机
eth1 互联T1汇聚交换机
eth2 互联T2汇聚交换机

关于DHCP 无线网段的地址池在核心，所以配置dhcp se glo即可
11-15 21-25 31-35 41-45的有线接入 地址池在核心 网关在汇聚，所以需要配置dhcp中继，vlan208 209需要开启dhcp se glo

解释206 207绑定实例的原因：
核心交换机从整体来看划分成了三个部分，default（或者叫public）、Employee、Guest
业务流量根据题目需求 在不适用策略路由的前提下要经过防火墙，将核心和防火墙的vlan206都绑定Employee实例，且建立OSPF邻居后，核心Employee实例的网段下一条就只会是防火墙的vlan206 因为实例隔离，Employee的路由不会出现在public，同理，Guest选用vlan207即可。
然后从防火墙需要把流量引回核心的public，核心侧就不需要绑定实例，防火墙需要绑定实例。
